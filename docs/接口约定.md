## 1. 问答接口（前端 ↔ 后端）

```
POST /api/chat/stream
Content-Type: application/json

{ "question": "用户问题", "history": [] }
```

`history` 为此前的对话，格式 `[{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]`，第一阶段可传空数组。

返回 `text/event-stream`，每个事件形如：

```
event: token
data: {"delta": "字"}

```

| 事件 | data | 说明 |
|---|---|---|
| `tool_call` | `{"name": "search_knowledge_base", "args": {"query": "...", "top_k": 5}}` | 模型发起检索，前端显示“正在检索…” |
| `citations` | `[{"id": 1, "doc_name": "xx.pdf", "page": 3, "content": "..."}]` | 引用来源；答案中的 [1] 对应 id=1 |
| `token` | `{"delta": "..."}` | 答案片段，按顺序拼接 |
| `error` | `{"message": "..."}` | 出错 |
| `done` | `{}` | 本轮结束，**一定是最后一个事件** |

位置：`backend/citation/builder.py`
