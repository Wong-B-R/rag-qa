# frontend 目录（负责人：组员 A）

用 VibeCoding 生成问答页，整个前端工程放在本目录下。

## 页面需求

1. 提问输入框 + 发送按钮
2. 流式答案展示（逐字出现）
3. 检索状态提示：收到 `tool_call` 事件时显示“正在检索知识库…”
4. 引用来源卡片：收到 `citations` 事件后渲染，显示文档名和页码，点击可展开原文；答案中的 [1][2] 最好能点击跳到对应卡片

## 对接后端

- 后端地址：`http://localhost:8000`
- 接口：`POST /api/chat/stream`，请求体 `{"question": "...", "history": []}`
- 返回 SSE，事件格式见 `docs/接口约定.md`

注意：浏览器自带的 `EventSource` 只支持 GET，这里是 POST，需要用 `fetch` 读取流，自己按空行切分事件。给 VibeCoding 工具的提示词里写明这一点，可以少走弯路。

后端默认开着假数据模式，不用等其他人，启动后端即可联调。

## 开发服务器端口

后端已允许 `localhost:5173`（Vite 默认）和 `localhost:3000` 跨域访问。用其他端口请告诉项目经理。
